# IOC、DI

**IOC: **控制反转是一种设计思想，把对象的创建和依赖关系交个容器，而不是手动创建和管理。

在不使用IoC的情况下，我们很容易写出来这样的代码：

```ts
import { A } from './modA';
import { B } from './modB';

class C {
  constructor() {
    this.a = new A();
    this.b = new B();
  }
}
```

使用IOC方式后，由容器负责管理类C的依赖关系，当类C需要使用A、B时，容器会自动将A、B注入到类C中。

**DI** 的全称为 Dependency Injection，即依赖注入。依赖注入是控制反转的一种实现方式，它的思路就是在对象创建时自动注入依赖对象。

```ts
import 'reflect-metadata';

type Constructor<T = any> = new (...args: any[]) => T;

function Injectable() {
  return (target: Constructor) => {
    return target;
  };
}

@Injectable()
class A {
  getName() {
    return 'A';
  }
}

@Injectable()
class B {
  constructor(private a: A) {
    console.log('a', this.a.getName());
  }
}

@Injectable()
class B2 {
  constructor(private a: A) {
    console.log('a', this.a.getName());
  }
}

class Container {
  private providers = new Map();

  get<T>(target: Constructor<T>): T {
    if (this.providers.has(target)) {
      return this.providers.get(target);
    }
    const paramTypes = Reflect.getMetadata('design:paramtypes', target) || [];
    const instance = new target(...paramTypes.map((type: Constructor) => this.get(type)));
    this.providers.set(target, instance);
    return instance;
  }
}

const container = new Container();
const b = container.get(B);

```
