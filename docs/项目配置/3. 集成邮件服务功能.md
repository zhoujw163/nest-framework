# 集成邮件服务功能

商业化的邮件服务（性价比较高的）有：
- 国外：SES、Mailgun 等。
- 国内：SendCloud 等。

如果是个人项目，推荐使用 Qq 邮箱或 163 邮箱等。

## 实现邮件收发功能

- 发邮件用 SMTP 协议。
- 收邮件用 POP3 协议、或者 IMAP 协议。

在 node 里也有对应的包，发邮件用 `nodemailer` 包，收邮件用 `imap` 包。
而在 nest 里，有一个 `@nestjs-modules/mailer` 包，它封装了 `nodemailer` 包，提供了更方便的使用方式。

https://www.npmjs.com/package/@nest-modules/mailer
https://nest-modules.github.io/mailer/docs/mailer.html#install

依赖库：
- `@nestjs-modules/mailer`
- `nodemailer`
- `handlebars`
- `preview-email`

**邮件模版：**

在 `common/mail/templates` 目录下创建 `welcome.hbs` 文件，内容如下：

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>邮件通知</title>
</head>
<body>
  <h1>hello {{name}}</h1>
  <p>您的账号已成功注册。</p>
</body>
</html>
```

**mail.module.ts：**

```ts
// common/mail/mail.module.ts
import { MailerModule } from '@nestjs-modules/mailer';
import { Module } from '@nestjs/common';
import { HandlebarsAdapter } from '@nestjs-modules/mailer/dist/adapters/handlebars.adapter';

@Module({
  imports: [
    MailerModule.forRoot({
      transport: 'smtps://joaha@qq.com:fujczzmuhptijbbj@smtp.qq.com',
      defaults: {
        from: '"zhoujw test" <joaha@qq.com>',
      },
      template: {
        dir: __dirname + '/templates',
        adapter: new HandlebarsAdapter(),
        options: {
          strict: true,
        },
      },
    }),
  ],
})
export class MailModule {}
```

在 app.controller.ts 中添加一个方法，用于发送邮件：

```ts
// app.controller.ts
import { Controller, Get } from '@nestjs/common';
import { MailerService } from '@nestjs-modules/mailer';

@Controller()
export class AppController {
  constructor(private readonly mailerService: MailerService) {}

  @Get('mail')
  sendMail(): void {
    this.mailerService
      .sendMail({
        to: '1227364071@qq.com',
        from: 'joaha@qq.com',
        subject: 'Testing Nest Mailermodule with template ✔',
        template: 'welcome', // The `.pug`, `.ejs` or `.hbs` extension is appended automatically.
        context: {
          // Data to be sent to template engine.
          name: 'joaha',
        },
      })
      .then(() => {
        console.log('邮件发送成功');
      })
      .catch((err) => {
        console.log('邮件发送失败', err);
      });
  }
}
```

**配置 nest-cli.json：**

在 nest-cli.json 中添加如下配置：

```json
"compilerOptions": {
  "watchAssets": true,
  "assets": ["common/mail/templates/**/*.hbs", "assets/**/*"]
},
```
